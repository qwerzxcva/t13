# t13 (事件与统计归档)

## 目录
```
events/          涨跌事件归因 (YYYY-MM-DD.md: 当日大涨/大跌/涨停原因分类)
fundflow/        资金流快照 (YYYY-MM-DD.csv)
hotspots/        热点题材追踪 (题材名.md: 持续时间/龙头/发酵路径)
news/            7x24新闻按日归档
stats/           长周期统计 (打板晋级率/周期规律/日历效应)
```

## 数据源
- 涨停池: 东财 push2ex (原因分类字段)
- 新闻: 新浪 7x24
- 资金流: 新浪/东财 (云端 Actions 采集)
- 统计: 本地全量库计算后归档
