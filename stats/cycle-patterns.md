## 四、连涨连跌段结构（822 交易日）

**连涨**（228 段）：1天 21.5% → 2天 32.0% → 3天 20.6% → 4天 14.0% → ≥5天 11.9%
**连跌**（102 段）：1天 52.0% → 2天 22.5% → 3天 15.7% → ≥4天 9.8%

**规律（超短核心）**：
1. 跌市比涨市"短促"：一半连跌只跌 1 天就修复（超跌反弹是常态，**连跌 1 天后抄底胜率天然高**）
2. 连涨 2 天的段最多（32%），**连涨 2 天后追高的胜率开始下降**；连涨 ≥4 天仅占 14%——强势股第 4 天以后风险陡增
3. 大涨(>2%)与大跌(<-2%)完全对称：各 17 次/822 天（4.1%），恐慌与亢奋等概率出现

2. 涨停家数 <150 为冰点区（出手好时机、低吸为主），>500 为亢奋区（高位股风险>机会、防炸板潮），300-400 为健康主升区
3. 跌停>200 家（2月/5月/9月）= 恐慌释放期，次日超跌反抽概率大
4. 本轮 10 月开局日均 185 家：情绪处于**中性偏低**区，非冰点非亢奋——超短以低吸准涨停/首板为主，不打高位板

## 六、可复现性

统计基于本地库：`~/stockdb/scripts/query.py "SQL"`（DuckDB 直查 Parquet）。核心 SQL 模板：

```sql
-- 星期效应
SELECT dayofweek(CAST(date AS DATE)) dw, avg(100*(close/lag(close) OVER (ORDER BY date)-1))
FROM read_parquet('~/stockdb/data/index/*.parquet') WHERE symbol='sh000001' GROUP BY 1;

-- 每日涨停家数
SELECT date, sum(CASE WHEN close>=high*0.999 AND (symbol LIKE 'sh60%' OR symbol LIKE 'sz00%') THEN 1 ELSE 0 END)
FROM read_parquet('~/stockdb/data/kline/*/*.parquet') GROUP BY date;
```
